# App de Análise da Reforma Tributária

Este aplicativo é projetado para analisar o impacto da nova reforma tributária brasileira sobre notas fiscais eletrônicas (NFE) de compra e venda de produtos.

## Estrutura de Diretórios

- `tabelas_nfe/`: Diretório dedicado para armazenar planilhas (CSV, Excel, etc.) contendo dados de notas fiscais (vendas, compras, códigos de produtos, NFE, etc.).
- `dados_reforma/`: Diretório dedicado para armazenar parâmetros, tabelas de alíquotas, porcentagens e novas regras publicadas sobre a reforma tributária.

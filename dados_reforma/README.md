# Dados e Alíquotas da Reforma Tributária

Deposite neste diretório os arquivos de parâmetros com as regras, alíquotas (IBS, CBS, Imposto Seletivo, etc.), porcentagens de transição e tabelas oficiais publicadas sobre a reforma tributária.

O aplicativo lerá estes arquivos para recalcular o impacto dos tributos sobre as notas fiscais depositadas na pasta `tabelas_nfe`.

# Histórico de Alterações de Alíquotas

Este diretório armazena os logs individuais de cada alteração de alíquota detectada pelo script de atualização diária.

Cada arquivo será nomeado no formato `historico_YYYYMMDD_HHMMSS.json` e conterá:
- Data e hora da detecção da mudança
- Alíquotas antiga e nova de CBS/IBS
- Fonte da atualização
